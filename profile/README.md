## Open source

### [Noburi](https://github.com/useburoo/noburi)

**Your agents, at work.** A local-first desktop studio for directing Claude Code agents from a cozy pixel office.

- Finds your local Claude Code projects and sessions, reads their history, continues or forks a session with approvals
- Missions of up to three tasks run by Claude Code agents, saved locally in SQLite
- A pixel office that shows what each agent is really doing
- TypeScript, React, Tauri 2 · Apache-2.0 · early alpha

[Repository](https://github.com/useburoo/noburi) · [Website](https://noburi.jiordiviera.me)
